# TrevorGames website: GitHub Pages handoff

You're taking over deployment of Trevor's studio website. It's built, reviewed and ready. What's left is putting it
live on GitHub Pages, and later on a custom domain.

## What it is

A hand-written static site with no build step needed to serve it: plain HTML, one CSS file (`assets/css/site.css`),
one small JS file (`assets/js/site.js`), and self-hosted fonts. No frameworks, trackers or cookies. Every internal
link and asset path is relative, so it works under `/trevorg/` on github.io and at a domain root later.

| Page | File |
|---|---|
| Home: wordmark, trailer, the four games, follow links | `index.html` |
| Game pages: key art, About, screenshot gallery with lightbox, clips | `games/engagement/`, `games/fight/`, `games/street-takeover/`, `games/field-surgeon/` |
| Press kit: factsheet, descriptions, full-size key art and screenshots | `press/index.html` (files in `assets/press/<game>/`) |
| Not found | `404.html` (works from any path) |
| Extras | `robots.txt`, `sitemap.xml`, `.nojekyll`, `favicon.ico`, one 1200x630 Open Graph image per page in `assets/img/og/` |

Checked before handoff: 7 pages rendered at 1440, 390 and 360 px wide with no sideways scroll; tap targets 44 px or
larger; link check 0 problems (`python3 tools/site/linkcheck.py`); home page about 0.8 MB at 1x and 1.5 MB at 3x
before the trailer plays.

## Steps

1. **Merge `website` into `main`.** It's a fast-forward: `git checkout main && git merge --ff-only website && git push`.
   If you're working from the zip instead, copy everything in its `site/` folder into the repo root on `main`, next to
   the media folders above, and push.
2. **Turn on Pages.** Repo Settings > Pages > Build and deployment > Source: **Deploy from a branch** > Branch: **main**,
   folder **/ (root)** > Save. If your GitHub tools can't change repository settings, ask Trevor to click this; it takes
   a few seconds.
3. **Check it.** After a minute or two:
   - `curl -I https://trevorparker-hash.github.io/trevorg/` returns 200, and so does `.../trevorg/games/fight/`.
   - `.../trevorg/games/nope/` returns 404 and shows the styled 404 page.
   - `.../trevorg/assets/img/og/home.jpg` returns 200 (used for link previews).
   - In a real browser, press play on the home trailer and on one game clip. The pre-handoff tests ran in a headless
     browser without an H.264 decoder, so actual playback hasn't been seen yet.
4. **Tell Trevor the link** and suggest using it as the link in his social bios. Right now they point at
   https://store.steampowered.com/search/?developer=Trevor.

## Rebuilding

The pages are generated by `tools/site/build.py`, and committing its output is how the site is updated. Paths are
relative to the repo root.

- `python3 tools/site/build.py` writes every page, `robots.txt`, `sitemap.xml` and `.nojekyll`. It was confirmed to
  reproduce the current files exactly.
- `tools/site/dl.py` downloads Steam store assets, `derive.py` makes the image sizes (needs ImageMagick and ffmpeg),
  `og.py` makes the Open Graph images, and `about.py` cleans the store's About text. Store data:
  `tools/site/data/steam_games.json`.
- `python3 tools/site/linkcheck.py` must print `PROBLEMS: 0`.
- `render.mjs`, `verify.mjs` and `interact.mjs` are headless Chromium checks that need `playwright-core`. Fix the paths
  at their tops before using them.

## Copy rules (keep them when editing)

- Every claim about a game must match its Steam store text. No release dates, no prices, and no platforms beyond what
  the store lists.
- Never name or describe the three games still awaiting Steam approval. The most the site says is "More games are on
  the way."
- No em-dashes or en-dashes used as dashes. Concrete over adjectives. No hype words. The studio speaks in the first
  person singular ("I make games on my own").
- Exact names: Engagement, FIGHT, Street Takeover, Field Surgeon, TrevorGames.
- Every Steam link carries `utm_source=website&utm_medium=web&utm_campaign=<home|game|press>&utm_content=<game-id>`.
- Socials: X https://x.com/TrevorGamesHQ, Bluesky https://bsky.app/profile/trevorgameshq.bsky.social, TikTok
  https://www.tiktok.com/@trevorgameshq, YouTube https://www.youtube.com/@TrevorGamesHQ. Instagram isn't set up yet,
  so it isn't linked.
