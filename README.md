# TrevorGames media (trevorg)

Public copies of the images and short clips that the TrevorGames social accounts post. They are hosted here so
the scheduler can fetch them by URL.

Everything is cut from the games' own Steam trailers and store art:

- Engagement: https://store.steampowered.com/app/5195200/Engagement/
- FIGHT: https://store.steampowered.com/app/5200410/FIGHT/
- Street Takeover: https://store.steampowered.com/app/5311310/Street_Takeover/
- Field Surgeon: https://store.steampowered.com/app/5339030/Field_Surgeon/

Each game folder has `<game>_v1..v3.mp4` (vertical 1080x1920), `<game>_wide.mp4` (1920x1080),
`post_intro_1080x1350.jpg` and `post_square_1080x1080.jpg`. `trevorgames/` has the studio avatar, banners and
intro posts.
